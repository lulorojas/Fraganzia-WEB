# 📱 Flyers de Instagram - Fraganzia

## ✨ Archivos creados

Se han creado 3 flyers para historias de Instagram con motivo del lanzamiento:

1. **story-aniversario.html** - 🎉 Celebración del primer aniversario y lanzamiento de la web
2. **story-pedidos.html** - 🛒 Anuncio de pedidos online disponibles
3. **story-descuento.html** - 💝 Promoción de bienvenida con 20% de descuento

## 📐 Especificaciones

- **Dimensiones:** 1080 x 1920 píxeles (formato de historias Instagram)
- **Formato:** HTML con CSS y animaciones
- **Diseño:** Gradientes modernos estilo Instagram con iconografía del logo

## 🎨 Cómo usar

### Opción 1: Vista previa en navegador
```bash
# Abrí el archivo index.html en tu navegador para ver todos los flyers
public/flyers/index.html
```

### Opción 2: Captura desde el navegador
1. Abrí cada archivo HTML individual en tu navegador
2. Usá F12 para abrir DevTools
3. Activá el modo responsive (Ctrl+Shift+M)
4. Configurá las dimensiones a 1080 x 1920
5. Capturá la pantalla completa

### Opción 3: Desde el celular (RECOMENDADO)
1. Abrí los archivos HTML en el navegador de tu celular
2. Hacé screenshot directamente
3. La calidad será perfecta para Instagram Stories

## 🚀 Subir a Instagram

1. Abrí Instagram
2. Tocá el ícono + y seleccioná "Historia"
3. Seleccioná la imagen capturada
4. Publicá directamente sin filtros adicionales (ya están optimizados)

## 📝 Mensajes incluidos
